# OrbitalMechanics-project
Group project: Interplanetary Orbital Transfer

HOW TO GET THE REPOSITORY?
go to the link below:
https://github.com/RiccardoCaccia923/OrbitalMechanics-project
click on the button "code" and copy that link
then go on the terminal or VSpro or GIT bash and use: 
cd name-repo-where-you-can-put-the-work     example: cd onedrive/desktop/Orbital-Mechanics
git clone link-copied
git pull

MAIN COMMANDS
git pull            import the remote version on your local
git push            send your local version on the remote
git status          tell status of your local repo respect to the remote
git add .           add all the modified files to be ready for commit
git commit -m ""    create a commit, in the "" put a message about what you  have done
git restore .       cancel your local changes coming back to last commit

IMPORTANT
before to start working always do: git pull in order to work on the last version of the code
